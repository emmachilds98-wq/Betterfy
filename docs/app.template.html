Betterfy

Find the duplicates, catch what's filed in the wrong playlist, and empty the liked-songs backlog you've been ignoring since 2021.

Runs entirely in this browser. Your library never leaves it, and nobody else can see what you do here.

Duplicates that matter

Matches on ISRC, so a remaster and a re-issue are caught while a remix or extended mix is left alone.

Misfiles, by axis

A genre playlist is only compared with other genre playlists, so a track in a mood playlist isn't wrongly flagged.

Backlog inbox

Work through liked-but-unfiled tracks one at a time, with a suggested home and one key to file it.

Cross-filing left alone

A track in five playlists is usually deliberate. It's surfaced for you, never removed automatically.

Setup

This exact string must be saved as a Redirect URI on the Spotify app, and saved with Add then Save — adding without saving looks identical until sign-in fails.
Use a different Spotify app

Create one at developer.spotify.com/dashboard, tick Web API, add the redirect URI above, then paste the client ID. Stored only in this browser; no secret is needed.

Where the genres come from

Spotify no longer tells anyone the genre of a track, so Betterfy uses Last.fm's artist tags instead — the labels listeners actually apply to music. Those ship with the page, and you can top them up for your own artists from the Playlists screen. Source on GitHub.

Data sources

Track and playlist data from the Spotify Web API. Genre tags from Last.fm. Release styles from Discogs. Tempo and musical key data from GetSongBPM.
